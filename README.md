🌤️ Weather Project – Description
📌 Overview
This project fetches real-time weather data for any city using Python and the OpenWeatherMap API. It displays temperature, humidity, weather conditions, and more in a user-friendly format.

⚙️ Technologies Used
Python 3

Requests library for HTTP requests

OpenWeatherMap API

Git and GitHub for version control

🧠 Features
Get current weather for any city.

Displays:

Temperature

Humidity

Wind Speed

Weather Description

Easy-to-read terminal output.

GitHub-ready structure with README.
